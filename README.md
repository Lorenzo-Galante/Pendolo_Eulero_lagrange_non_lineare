# Notebook Colab interattivo sul pendolo semplice

Notebook didattico interattivo sul pendolo semplice, dedicato alle equazioni di Eulero–Lagrange e alla dinamica non lineare.

## Notebook

Il notebook può essere aperto direttamente in Google Colab oppure scaricato e modificato localmente in un ambiente Jupyter compatibile.
